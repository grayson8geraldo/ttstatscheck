# TikTok Ads Stats to Google Sheets

Chrome-расширение для автоматического сбора статистики из TikTok Ads Manager и экспорта в Google Sheets.

## Возможности

- Автоматический сбор данных из таблицы TikTok Ads Manager
- Метрики: **Расход (Spend)**, **CPC**, **CPL/CPA**
- Экспорт в Google Sheets с настраиваемыми столбцами
- Предпросмотр данных перед отправкой
- Два режима записи: добавление в конец или перезапись

## Установка

### 1. Настройка Google Cloud Project

1. Перейдите в [Google Cloud Console](https://console.cloud.google.com/)
2. Создайте новый проект или выберите существующий
3. Включите **Google Sheets API**:
   - Перейдите в **APIs & Services** > **Library**
   - Найдите "Google Sheets API" и нажмите **Enable**
4. Создайте OAuth 2.0 credentials:
   - Перейдите в **APIs & Services** > **Credentials**
   - Нажмите **Create Credentials** > **OAuth client ID**
   - Тип приложения: **Chrome Extension**
   - Укажите ID расширения (получите его после загрузки в Chrome, шаг 2)
   - Скопируйте **Client ID**

### 2. Установка расширения

1. Откройте `manifest.json` и замените `YOUR_GOOGLE_CLIENT_ID.apps.googleusercontent.com` на ваш Client ID из шага 1
2. Откройте Chrome и перейдите в `chrome://extensions/`
3. Включите **Режим разработчика** (переключатель в правом верхнем углу)
4. Нажмите **Загрузить распакованное расширение**
5. Выберите папку с файлами расширения
6. Скопируйте **ID расширения** и укажите его в OAuth credentials (шаг 1.4)

### 3. Настройка Google Таблицы

1. Создайте Google Таблицу или откройте существующую
2. Скопируйте ID таблицы из URL:
   ```
   https://docs.google.com/spreadsheets/d/ЭТОТ_ID_НУЖНО_СКОПИРОВАТЬ/edit
   ```
3. Рекомендуемая структура первой строки (заголовки):

   | A | B | C | D | E | F |
   |---|---|---|---|---|---|
   | Кабинет | Кампания | Расход | CPC | CPL | Дата |

## Использование

1. Откройте [TikTok Ads Manager](https://ads.tiktok.com/) в браузере
2. Перейдите в раздел со статистикой кампаний
3. Убедитесь, что таблица с данными загружена на странице
4. Нажмите на иконку расширения в панели Chrome
5. При первом использовании:
   - Укажите ID Google Таблицы
   - Настройте соответствие столбцов
   - Нажмите **Сохранить настройки**
   - Нажмите **Авторизоваться в Google**
6. Нажмите **Собрать и отправить в Sheets**
7. Проверьте данные в предпросмотре
8. Нажмите **Отправить в Google Sheets**

## Настройки столбцов

Вы можете указать, в какие столбцы Google Таблицы будут записываться данные:

| Параметр | По умолчанию | Описание |
|----------|-------------|----------|
| Кабинет | A | Название рекламного кабинета |
| Кампания | B | Название кампании |
| Расход | C | Потраченный бюджет (Spend/Cost) |
| CPC | D | Стоимость за клик |
| CPL | E | Стоимость за лид/результат |
| Дата | F | Дата сбора данных |

## Режимы записи

- **Добавить в конец** — данные добавляются после последней заполненной строки
- **Перезаписать** — данные записываются начиная с указанной начальной строки

## Решение проблем

### Данные не собираются
- Убедитесь, что вы на странице `ads.tiktok.com` с открытой таблицей статистики
- Прокрутите страницу, чтобы таблица полностью загрузилась
- Попробуйте обновить страницу и подождать полной загрузки

### Ошибка авторизации Google
- Проверьте, что Client ID в `manifest.json` указан правильно
- Убедитесь, что Google Sheets API включён в вашем проекте
- Попробуйте нажать "Переавторизоваться"

### Ошибка записи в Google Sheets
- Проверьте, что ID таблицы указан правильно
- Убедитесь, что у вас есть доступ на редактирование таблицы
- Проверьте название листа в настройках
